DeepSeek Harness — Help

Quick start

  1. Go to Basic Settings and check Enable service.
  2. (Optional) Edit API & Model to set your DeepSeek API key.
  3. Open the Install tab and click Install / Update.
  4. Wait ~2-5 minutes for the bundle to download and extract.
  5. Go back to Status — it should show Running.

What is this plugin?

This is a LuCI front-end for deepseek-harness, an AI agent framework by DeepSeek. The plugin downloads a precompiled dsh runtime bundle (Node.js 22.23.0 musl + dsh 0.1.0-rc.7) and runs it as a procd-managed HTTP service on your router.

Requirements

  • iStoreOS 24.10.8 or any OpenWrt 24.10.x
  • Architecture: x86_64 or aarch64
  • libc: musl (iStoreOS default)
  • RAM: ≥ 1 GB (dsh recommends ≥ 1 GB)
  • Disk: ≥ 500 MB free in /opt for the bundle

CLI

dsh-env setup      # install/update bundle
dsh-env status     # show state
dsh-env logs       # tail logs
dsh-env start|stop|restart
dsh-env config     # print UCI config
dsh-env shell      # enter runtime shell

Troubleshooting

  • Bundle download fails: check DNS + HTTPS connectivity to github.com / npmmirror.com
  • Node binary not executable: verify arch with uname -m, set UCI arch explicitly
  • dsh exits immediately: check dsh-env logs for missing dependencies (python3-light)
  • LAN clients can't connect: if listen_host=127.0.0.1, enable relay_enabled=1
